# Labels

A lightweight, customizable label mod for Geometry Dash that displays useful real-time gameplay statistics with minimal performance impact.

# Features

- FPS Counter
- CPS Counter
- Attempts Counter
- Best Progress
- Run from
- Current %
- Session Time
- Level ID
- Level song name
- Level's object count
