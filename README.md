<p align="center">

</p>

<p align="center">
A lightweight, customizable label mod for Geometry Dash that displays useful real-time gameplay statistics with minimal performance impact.
</p>

<p align="center">
# Features
</p>

<p align="center">
- FPS Counter
- CPS Counter
- Attempts Counter
- Best Progress
- Run from
- Current %
- Session Time
- Level ID
- Level song name
- Level's object count
</p>
